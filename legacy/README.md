# Legacy Reference

`cims-v0.13` adalah working build JavaScript sebelum migrasi TypeScript. Gunakan hanya untuk contract parity dan compatibility proxy selama fase transisi. Jangan menambahkan fitur baru ke legacy source.

Contoh menjalankan legacy pada port 3001:

```bash
cd legacy/cims-v0.13
API_PORT=3001 node apps/api/src/server.mjs
```
