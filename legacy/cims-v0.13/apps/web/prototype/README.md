# CIMS UI Workflow Prototype

Prototype ini memakai HTML, CSS, dan JavaScript tanpa dependency eksternal.

## Menjalankan

Buka `index.html` langsung di browser, atau dari root repository:

```bash
npm run prototype
```

Alur utama:

1. Record judicial determination.
2. Buka Scheduling.
3. Pilih Ruang A pukul 09:00 untuk mensimulasikan conflict.
4. Ubah ke Ruang B, jalankan conflict check, lalu approve schedule.
5. Lihat audit timeline.

Semua data bersifat sintetis. Prototype bukan aplikasi produksi.
